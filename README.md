# git-practice

A beginner-friendly project created to learn and practice **Git, GitHub, and version control** using Visual Studio Code.

## About

This repository is part of my journey to understand how developers manage projects with Git and collaborate through GitHub.

Throughout this project, I am practicing the fundamentals of:

* Creating and managing repositories
* Initializing Git repositories
* Staging files
* Creating commits
* Tracking changes
* Connecting local projects to GitHub
* Pushing projects to remote repositories
* Working with branches

## Tools Used

* Visual Studio Code
* Git
* GitHub

## Goal

The goal of this project is to build a strong foundation in Git and GitHub so I can confidently use version control in future web development and AI projects.

## What I'm Learning

Understanding repositories, commits, branches, pushing, pulling, and managing project history with Git.
